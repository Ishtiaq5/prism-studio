# Prism Studio - Gradient & Glow Lab

A tiny, dependency-free gradient designer for the web. Mix three colors, pick a
shape (linear / radial / conic), tune the angle, glow and corner radius - then
copy production-ready CSS in one click.

## Features

- Live preview that updates as you drag
- 10 curated presets to start from
- Randomize button for instant inspiration
- Animated gradient option with matching `@keyframes`
- Copy-to-clipboard with a legacy fallback
- Fully responsive from 360px up, semantic HTML, ARIA labels

## Stack

Vanilla HTML + CSS + JavaScript. No frameworks, no CDN, no build step.
Open `index.html` in any modern browser - that is the whole install process.
